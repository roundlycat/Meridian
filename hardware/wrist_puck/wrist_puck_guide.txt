1. Project Overview
The Wrist-Puck is a compact, wrist-worn haptic feedback device that combines two 
distinct sensory channels into a single 68 mm puck form factor. It is designed for 
use in VR/AR research, accessibility interfaces, and experimental interaction design.
Dual-Channel Architecture
● Texture Channel: A 10 mm coin-type Linear Resonant Actuator (LRA) driven 
by a TI DRV2605L haptic controller. This channel delivers fine vibrotactile 
patterns including clicks, buzzes, and textural feedback using the 
DRV2605L’s built-in 123-effect waveform library or real-time playback (RTP) 
mode.
● Weight-Shift Channel: An Adafruit SG51R sub-micro servo actuates a 
sliding brass mass (~8–10 g) along a 30 mm linear rail inside the enclosure. 
As the mass moves, the user perceives a shift in weight or tilt on the wrist, 
simulating directional force cues.
The device is controlled wirelessly via Wi-Fi/UDP using JSON-formatted haptic motifs. 
A Seeed Studio XIAO ESP32-C3 serves as the brain, providing Wi-Fi 802.11 b/g/n, 
BLE 5.0, USB-C connectivity, and built-in LiPo charging in a tiny 21×17.8 mm 
package.
Key Specifications

Power Notes
Important — Power Considerations
•  The XIAO ESP32-C3 has a built-in LiPo charge IC. Connect the LiPo directly to 
the BAT pads on the XIAO.
•  The servo draws from the 5 V USB rail. When on battery only, the 3.3 V 
output may not be sufficient for the servo — consider a small boost converter 
(3.3 V → 5 V) for battery-only operation, OR accept reduced servo torque at 
3.3 V.
CRITICAL — JST Polarity
Verify JST polarity before connecting any LiPo battery. The XIAO uses + on the 
left when the USB port faces you. Reversed polarity WILL destroy the board 
instantly.

Step 1: Print the Enclosure
9. Open wrist_puck_enclosure.scad in OpenSCAD.
10.Set RENDER = "bottom" → Press F6 (full render) → Export as bottom_shell.stl.
11.Set RENDER = "lid" → Press F6 → Export as lid.stl.
12.Slice at 0.2 mm layer height, 20% infill, PLA or PETG, no supports needed.
13.Print time: ~1.5 hours total for both parts.
14.Test-fit snap: the lid should click into the bottom shell with light pressure.
Step 2: Prepare the Perfboard Junction
15.Cut perfboard to ~20×15 mm.
16.Solder a 3-pin header row for the power bus (+3.3 V, +5 V, GND).
17.Solder the 100k/100k voltage divider (VBAT → midpoint → GND).
18.Add 4.7 kΩ I2C pull-up resistors if your DRV2605L breakout doesn’t have 
them.
19.Run hookup wires from the junction to each component location (leave 40 
mm leads).
Step 3: Wire the DRV2605L Breakout
20.Solder 4 wires to DRV2605L: VIN, GND, SDA, SCL.
21.Solder the LRA motor leads to the OUT+/OUT– pads on the DRV2605L.
22.Use JST connectors for detachable connections, or solder directly for a 
permanent build.
23.Test I2C address detection before installing in enclosure (address should read 
0x5A).
Step 4: Wire the SG51R Servo
24.The SG51R comes with a standard 3-pin servo connector (Brown = GND, Red 
= VCC, Orange = Signal).
25.Trim wires to ~60 mm.
26.Solder or crimp JST-PH connectors for clean routing.
27.Attach the smallest servo horn (single-arm) — this will push the sliding mass.
Step 5: Prepare the Sliding Mass Assembly
28.Thread 2× M5 brass nuts onto a short piece of brass rod, or use a single 
brass slug (~8–10 g).
29.Drill a 1 mm hole in the mass for a short linkage wire to the servo horn.
30.Verify the mass slides freely in the 6 mm × 30 mm rail slot in the enclosure.
31.Attach to the servo horn tip with a small Z-bend linkage wire.
Step 6: Install Components in Enclosure
32.LRA: Press-fit the LRA into the floor pocket (LRA face down toward skin side). 
Secure with a tiny drop of CA glue.
33.LRA wiring: Route LRA wires through the floor channel up to the DRV2605L 
pocket.
34.Servo: Seat the SG51R servo in its cavity. The servo ears should rest on the 
cavity ledges. Secure with M2 screws or friction fit.
35.Sliding mass: Place the sliding mass in the rail slot. Connect the linkage to 
the servo horn.
36.DRV2605L: Mount the DRV2605L breakout in its pocket. Use double-sided 
foam tape or M2 screws.
37.XIAO: Seat the XIAO ESP32-C3 in its pocket with the USB-C port aligned to 
the wall cutout.
38.Battery: Place the LiPo battery in its compartment. Secure with a small strip 
of foam tape. Do NOT compress the battery.
39.TP4056 (optional): If using the TP4056 separately, mount it in the rear 
pocket with USB-C port aligned to the rear wall cutout.
40.Perfboard: Place the perfboard junction on top of the battery compartment.
41.Wire routing: Route all wires through the floor channels. Tuck excess wire 
neatly.
42.Close: Snap the lid on. Verify the LRA window aligns with the LRA and the 
status LED window aligns with the XIAO LED.
Step 7: Flash the Firmware
43.Connect the XIAO to your computer via USB-C.
44.In Arduino IDE: Install ESP32 board support via Board Manager (Espressif 
ESP32, version 3.x).
45.Select board: XIAO_ESP32C3.
46.Install libraries: ESP32Servo, ArduinoJson (v7), Wire (built-in).
47.Open wrist_puck_haptic_node.ino.
48.Edit WIFI_SSID and WIFI_PASS constants to match your 2.4 GHz network.
49.Upload (hold BOOT button if needed during upload).
50.Open Serial Monitor at 115200 baud to watch calibration output.

6. JSON Motif Schema Reference
The Wrist-Puck accepts haptic motifs as JSON payloads sent via UDP on port 9000. 
Each motif is a self-contained sequence of channel actions.
Base Schema
{   "id": "motif_name",   "repeat": 1,   "steps": [     {       "ch": "lra", 
"type": "effect",       "effect": 47,       "dur_ms": 200     }   ] }
Top-Level Fields
Field Type Range Description
id string — Human-readable 
name for the motif
repeat int 1–10 Number of times 
to play the full 
sequence
steps array — Ordered list of 
channel actions
Step Fields — LRA Channel ("ch": "lra")
Type Value Additional Fields Description
"effect" "effect": 1–123 Play a DRV2605L library 
effect. See TI DRV2605L 
datasheet Table 11.2 for 
the full waveform library.
"rtp" "amplitude": 0–255 Real-Time Playback 
mode. Continuous 
vibration at specified 
intensity.
"stop" — Stop LRA output 
immediately.
Step Fields — Servo Channel ("ch": "servo")
Type Value Additional Fields Description
"pos" "pos_us": 750–2250 Move to position specified 
in microseconds pulse 
width.
"center" — Return to center position 
(1500 μs).
"sweep" — Execute a full left–right–
center sweep test.
Common Step Field
Field Type Range Description
dur_ms int 0–5000 Dwell time in 
milliseconds after 
executing this 
step before the 
next step begins.
