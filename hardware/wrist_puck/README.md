# Wrist-Puck Dual-Channel Haptic Node

## Overview
This directory contains the physical design files and geometry constraints for the Embodied Judgment "Wrist-Puck" haptic node.

## Current Status
- **Enclosure:** Initial OpenSCAD design (`wrist_puck_enclosure_1.scad`) in progress. 76mm diameter.
- **Fabrication:** To be printed at Yukonstruct.

## Geometry & Components (Pending Validation)
- 68mm-76mm diameter cylinder, ~22mm tall
- LRA (10mm coin) press-fit into the floor
- 30mm linear rail for sliding mass
- SG51R servo
- XIAO microcontroller (USB-C wall access)
- DRV2605L motor driver
- Battery compartment
