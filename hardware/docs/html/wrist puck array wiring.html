5-LRA Array Wiring Guide

TCA9548A mux + 5× DRV2605L — replaces the single-LRA + servo build. Reference for the next bench session.

Each DRV2605L keeps the same fixed 0x5A address — the mux is what makes that safe. Only one channel is I2C-addressable at a time, but each board keeps driving its last-written RTP value continuously, so round-robin updates across channels still give you coordinated, near-simultaneous amplitude patterns for the phantom-array effect.

04 LRA wiring

ChannelActuatorPolarity
CH0 → DRV #1Flat LRA Adoesn't matter
CH1 → DRV #2Flat LRA Bdoesn't matter

CH3 → DRV #4Flat LRA Ddoesn't matter
CH4 → DRV #5Angled, off-centermark it — see below
DRV #5 drives the angled LRA bidirectionally (BIDIR_INPUT + signed RTP) for the directional-tug effect. Mark which lead is OUT+ with a dab of paint or a distinct heat-shrink color before it disappears into the enclosure — it's the one actuator here where "which way is positive" actually matters and needs to stay knowable later.

06 Not settled yet

  • Enclosure volume — Rev 5.0 was solved for 1 DRV + servo, not a mux + 5 DRV boards. Needs a re-run through the fit solver.
  • Physical distribution — assumed all 5 DRVs cluster in the puck with just the two bare LRA leads extended out to each position (same technique as the single-LRA build), but this hasn't been finalized against the "spaced along the band" concept.
  • Power budget — the mux only switches I2C access, not power, so all 5 DRV boards draw idle current simultaneously. Worth a bench measurement before finalizing regulator margin.
